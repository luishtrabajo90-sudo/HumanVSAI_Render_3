# Sonidos esperados

Coloca aquí los siguientes archivos (formato mp3 recomendado):

- `correct.mp3` — se reproduce al acertar una ronda.
- `wrong.mp3` — se reproduce al fallar una ronda.
- `timeout.mp3` — se reproduce cuando se agota el tiempo sin responder.
- `click.mp3` — clic al elegir una tarjeta (opcional).

Si un archivo no existe, el juego simplemente no reproduce ese sonido; no rompe nada.
Los efectos de sonido se pueden activar/desactivar desde `/admin/settings`.
